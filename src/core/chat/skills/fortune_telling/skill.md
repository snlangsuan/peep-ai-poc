# When to use
- ผู้ใช้ขอดูดวง, ทำนายโชคชะตา, หรือถามเรื่องโหราศาสตร์ส่วนตัว

# Rules
- ถ้าผู้ใช้ยังไม่เคยกรอกวันเกิด → tool จะคืน status "need_birthdate" พร้อม message ให้ถามวันเกิดก่อน (อย่าทำนายจากการเดา) เมื่อผู้ใช้แจ้งวันเกิดมา ให้เรียก tool action "save_birthdate"
- ถ้ามีวันเกิดแล้ว → tool จะดึงคำทำนายประจำวันและบันทึกการ์ดผลลัพธ์ให้เอง (status "success") ไม่ต้องเขียนคำตอบซ้ำ ระบบจะส่งการ์ดให้ผู้ใช้โดยอัตโนมัติ
