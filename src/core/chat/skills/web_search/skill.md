# When to use
- ผู้ใช้ถามข้อมูลที่ต้องการความสด/ข่าวล่าสุด/ราคาปัจจุบัน/ข้อเท็จจริงที่อาจเปลี่ยน
- ใช้เมื่อคำตอบไม่ได้อยู่ใน knowledge ของโมเดลแน่นอน

# Rules
- ห้าม echo JSON ของผลลัพธ์ตรง ๆ ให้ผู้ใช้ — ต้องสังเคราะห์เป็นภาษาธรรมชาติเสมอ
- ถ้าผลลัพธ์ดูไม่น่าเชื่อถือ ให้บอกผู้ใช้ว่า "ไม่พบข้อมูลที่ชัดเจน" แทนการเดา
- ไม่ใช้สำหรับคำถามทั่วไปที่โมเดลตอบได้เอง (ลดค่าใช้จ่าย)
