# When to use
- ผู้ใช้ถามว่า "เหลือเงินเท่าไหร่ / ยอดคงเหลือเดือนนี้ / สรุปบัญชี" → `manage_account(action='balance')`
- ผู้ใช้ตั้ง "เงินต้น / เงินตั้งต้น / มีเงินอยู่ ... บาท" → `manage_account(action='set_balance', amount=...)`
- ผู้ใช้ตั้ง/แก้ "งบเดือนนี้ / งบประมาณ ... บาท" → `manage_account(action='set_budget', budget=...)`; ยกเลิกงบ → `set_budget(clear=true)`

# โมเดลบัญชี (อธิบายให้ถูก)
- ยอดคงเหลือคิดแบบบัญชีจริง: **opening (ยอดยกมา) + รายรับ − รายจ่าย = closing (ยอดคงเหลือ)**
- closing ของเดือนนี้จะ "ยกไป" เป็น opening ของเดือนถัดไปอัตโนมัติ
- ถ้าผู้ใช้ "ตั้งเงินต้น" เดือนไหน เดือนนั้นจะใช้ค่าที่ตั้งเป็น opening แทนการยกยอด แล้วเดือนถัด ๆ ไปก็ยกยอดต่อจากนั้น
- รายรับ/รายจ่ายมาจากรายการที่บันทึกผ่าน `manage_expenses` (type income/expense) — ถ้าผู้ใช้ยังไม่เคยบันทึกอะไร ยอดอาจเป็น 0

# Month
- `month` รูปแบบ `YYYY-MM` เท่านั้น ถ้าผู้ใช้ไม่ระบุเดือน → ไม่ต้องส่ง month (ระบบใช้เดือนปัจจุบัน)
- map คำเป็นเดือน (ใช้ค่าจาก Current Thai local time block): "เดือนนี้"=เดือนปัจจุบัน, "เดือนที่แล้ว"=เดือนก่อนหน้า, "เดือนหน้า"=เดือนถัดไป

# Rules
- tool จะส่งการ์ด `balance` ให้ผู้ใช้เองและคืน `explanation` มาให้ — ถ้าจะตอบเสริมให้พูดสั้น ๆ สอดคล้องกับตัวเลขใน balance ห้ามแต่งตัวเลขเอง
- ถ้า `set_balance` ผู้ใช้ต้องระบุจำนวนเงินชัดเจน ถ้าไม่ชัดให้ถามก่อน
- การ "บันทึกรายรับ/รายจ่าย" (เช่น "ได้เงินเดือน 20000", "จ่ายค่าน้ำ 200") ให้ใช้ skill `expense_management` ไม่ใช่ skill นี้ — skill นี้ใช้เฉพาะ "เงินต้น/ยอดคงเหลือ/งบ"
