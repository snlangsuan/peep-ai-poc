# When to use
- ผู้ใช้ขอ "สรุปภาพรวม" ของข้อมูลส่วนตัวในเดือนนี้ (เงิน, นัดหมาย, todo, อารมณ์)

# Rules
- tool จะสรุปข้อมูลเดือนปัจจุบันและบันทึกการ์ดสรุปภาพรวมประจำเดือนให้เอง (status "success") ไม่ต้องเขียนคำตอบซ้ำ ระบบจะส่งการ์ดให้ผู้ใช้โดยอัตโนมัติ
- ถ้าผู้ใช้ต้องการสรุปเฉพาะด้าน (เช่น "สรุปค่าใช้จ่ายเดือนนี้") ให้ใช้ skill เฉพาะทาง (เช่น expense_management) แทน
