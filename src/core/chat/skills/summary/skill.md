# When to use
- ผู้ใช้ขอ "สรุปภาพรวม" ของข้อมูลส่วนตัว (เงิน, ประวัติคุย, แผน)

# Rules
- เครื่องมือนี้เป็นโครงร่างชั่วคราว — ผลลัพธ์อาจไม่สมบูรณ์
- ถ้าผู้ใช้ต้องการสรุปเฉพาะด้าน (เช่น "สรุปค่าใช้จ่ายเดือนนี้") ให้ใช้ skill เฉพาะทาง (เช่น expense_management) ก่อน
