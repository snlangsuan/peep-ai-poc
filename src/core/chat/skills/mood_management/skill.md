# When to use
- ผู้ใช้ขอดูสรุปอารมณ์ของตัวเอง, ถามว่า "ช่วงนี้รู้สึกยังไง", หรืออยากรู้แนวโน้มอารมณ์

# Rules
- เครื่องมือนี้ "อ่านอย่างเดียว" — ไม่ใช้สำหรับการ "บันทึก" อารมณ์ใหม่
- การอัปเดตอารมณ์เกิดผ่านการ์ดที่ระบบยิงให้ตอน 6 โมงเย็น ไม่ใช่ผ่าน chat
- ถ้าผู้ใช้พยายามบันทึกอารมณ์ผ่าน chat ให้บอกว่า "รอการ์ดอารมณ์ตอน 6 โมงเย็นนะ"
